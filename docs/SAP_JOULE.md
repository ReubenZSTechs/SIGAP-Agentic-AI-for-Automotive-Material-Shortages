### Getting Help

If you encounter difficulties accessing or using SAP AI services, raise an issue for help from the SAP mentoring team.

1. **Search existing issues**, including closed issues, to check whether your question has already been answered.
2. Open the [Issues tab](https://github.com/SAP-AWS-ID-Hackathon-2026/SAP_AWS_Hackathon_ID_2026/issues), click **New issue**, and select the help request template `Error Report` if prompted.
3. Use a descriptive title, such as `[Team 3] SAP AI Core — authentication error`.
4. Include your **team name, SAP service, question or problem, and what you have already tried**. Add relevant error messages or screenshots.
5. Keep follow-up updates in the same issue. Once resolved, share the solution and close the issue.

**Remove passwords, API keys, access tokens, and personal data before posting.**
